# 🚀 Overstay — Viral Growth Strategy

## The Viral Loop

```
┌──────────────────────────────────────────────────────┐
│                                                      │
│   1. Pre-Night: Upload photo → Get prediction        │
│              ↓                                       │
│   2. Share prediction card on social media           │
│              ↓                                       │
│   3. Friends see it → "I want to try this"           │
│              ↓                                       │
│   4. Friends use Overstay → Post their predictions   │
│              ↓                                       │
│   5. Morning-After: "AI WAS RIGHT 😭" post           │
│              ↓                                       │
│   6. Second viral moment → New wave of users         │
│              ↓                                       │
│   (Repeat every weekend)                             │
│                                                      │
└──────────────────────────────────────────────────────┘
```

**Key insight:** Every prediction has **two** viral moments:
1. **The prediction** (before / during the night)
2. **The resultado** (morning-after confirmation)

## Referral Mechanics

### Invite System
- Share prediction → friend scans QR or clicks link → both get a free premium prediction
- "Your friend thinks you won't leave before midnight. Prove them wrong."

### Group Dynamics
- Group predictions create natural sharing
- "Who's the most chaotic in the group?" → leaderboard share
- Friend tags in predictions

### Seasonal Spikes
Plan campaigns around peak nightlife moments:
- **New Year's Eve** — "Midnight prediction challenge"
- **St. Patrick's Day** — "Green chaos forecast"
- **Halloween** — "Costume chaos bonus"
- **Summer weekends** — "Rooftop bar edition"
- **Festival season** — "Multi-day chaos meter"
